PocketSkin telepítése

A PocketSkin telepíthető alkalmazásként is, ha GitHub Pages-en vagy más HTTPS-címen fut.

Android / Chrome: nyisd meg az oldalt, majd válaszd a böngésző menüjében az „Alkalmazás telepítése” vagy „Hozzáadás a kezdőképernyőhöz” lehetőséget.

iPhone / iPad: Safari → Megosztás → „Főképernyőhöz adás”.

Windows / macOS: Chrome vagy Edge címsorában keresd a telepítés ikont, vagy a böngésző menüjében az alkalmazás telepítését.
